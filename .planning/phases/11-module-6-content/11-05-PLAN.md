Build an interactive discount window visualization with loan calculator and rate corridor logic. Dashboard-style panel.

**Two sections:**

**Section A: Discount Loan Calculator**
- Slider: Face value ($1,000 to $100,000, default $10,000)
- Slider: Discount rate (1% to 15%, default 5.5%)
- Computed values (AnimatedValue):
  - Cash received today = Face value × (1 - discount rate)
  - Repayment at maturity = Face value
  - Effective cost = Face value × discount rate
- Show formula: "Cash received = Face value - (Face value × Discount rate)"
- Example: "$10,000 face, 5.5% rate → receive $9,450, repay $10,000"

**Collateral haircut table (expandable):**
| Collateral Type | Borrowing Power | Risk Level |
| 1-year U.S. Treasury | ~99% | Very Safe |
| Agency MBS | ~95% | Safe |
| Commercial loans | ~75% | Moderate |
| Commercial real estate | ~35-95% | Variable |
| Consumer loans | ~70% | Moderate |

**Section B: Rate Corridor Visualization**
- SVG vertical rate diagram showing:
  - Discount rate (top, red dashed line) — "Upper bound"
  - Federal funds target range (middle, blue band)
  - Federal funds rate (equilibrium dot within range)
- Slider: Target rate (0% to 6%, default 5.25%)
- Discount rate auto-computed: target range upper bound + 0.25% (or = upper bound in modern framework)
- Logic explainer: "If fed funds rate > discount rate → banks borrow from discount window instead → demand for interbank funds falls → pushes rate back down"
- Label: "Since 2003, primary credit rate always sits above federal funds rate"

- Median line connecting medians across years
