Build the comprehensive "Abundant Reserves Floor System" — a capstone widget that shows the complete modern monetary policy rate corridor. This is the "useful widget" that ties everything together. Dashboard-style panel with dials and controls.

**Regime Toggle:** Pre-2008 (Scarce Reserves) vs Post-2008 (Abundant Reserves)

**Pre-2008 (Scarce Reserves) view:**
- Supply/demand diagram for reserves (similar to OMO flow but focused on scarcity)
- Small supply, steep demand curve
- Show: "Small OMO changes move the rate"
- Key metrics: Reserves ~$14B (2007)
- Tools: OMOs (primary) + Discount Window (backup)

**Post-2008 (Abundant Reserves) view — THE MAIN DASHBOARD:**

**Rate Corridor Diagram (SVG, vertical rate axis):**
- Discount Rate (top, red) — "Ceiling: banks won't borrow interbank above this"
- IORB Rate (middle-high, blue) — "Floor for banks: won't lend below what Fed pays on reserves"
- Fed Funds Target Range (blue band between IORB and slightly below)
- Effective Fed Funds Rate (green dot within range)
- ON RRP Rate (bottom, purple) — "Sub-floor for non-banks: ensures money market funds don't lend below this"

**Interactive Controls (sliders):**
- Slider: FOMC Target Range (0%-6%, sets the band)
- When target changes: discount rate, IORB, and ON RRP auto-adjust:
  - Discount rate = target range upper bound + 0.25%
  - IORB = target range upper bound (or slightly above midpoint)
  - ON RRP = target range lower bound
- AnimatedValue displays for each rate

**Arbitrage Logic Panel (expandable):**
- IORB arbitrage: "If fed funds rate > IORB → banks lend in interbank market → arbitrage pushes rates toward IORB"
- IORB floor: "If fed funds rate < IORB → banks deposit with Fed instead → won't lend below IORB"
- ON RRP need: "Non-banks (money market funds) can't earn IORB → might lend below IORB → ON RRP gives them a Fed-backed alternative"
- ON RRP floor: "Non-banks won't lend for < ON RRP rate"

**Key Metrics Bar:**
- Reserve Balance: ~$3.2T (post-2008) vs ~$14B (pre-2008) — show dramatic difference
- "Traditional OMOs less effective: need massive reserve changes to move rates"
- "IORB + ON RRP: raise rates WITHOUT changing reserve supply"

**Bottom insight:** "The floor system allows the Fed to control interest rates even when bank reserves are abundant, using administered rates instead of scarce-reserve supply adjustments."

This component should feel like the control room of the Fed. Professional dashboard with clear cause-and-effect. Use all existing primitives (Slider, AnimatedValue, Entity). Keep under 1000 lines.
